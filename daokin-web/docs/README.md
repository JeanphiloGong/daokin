# Frontend Docs Map

This folder is for frontend-local documentation owned by `daokin-web`.

## Put Frontend Docs Here

- UI flow notes
- page and component architecture notes
- client-state guidance
- API integration notes specific to the web app
- frontend runbooks and troubleshooting notes

## Do Not Put These Here

- project-wide decisions
- shared governance and moderation policy
- shared architecture that spans frontend, backend, and contracts

Those belong in root `docs/`.

## Existing Anchors

- [AGENTS.md](../AGENTS.md)
- [README.md](../README.md)
- [../src](../src)

## Likely First Docs

- real API integration notes for the MVP flow
- UI state map for auth, create, join, exchange, and attribution
- accessibility and responsive verification notes
